# SOHBAT branding

SOHBAT means conversation in Persian. The identity uses a rounded blue microphone mark, Inter typography, restrained neutral surfaces, and a dark translucent recording capsule.

- `sohbat/assets/brand/logo.png`: image-generated microphone mark, 1254×1254 RGBA PNG. Transparent corners and a genuine alpha channel were validated.
- `sohbat/assets/brand/app.ico`: Windows icon sizes derived from the generated logo.
- `docs/assets/banner.png`: image-generated 2172×724 RGB README banner.
- `docs/assets/settings-light.png`: native Qt settings capture.

The logo and banner were generated with Codex's built-in image-generation tool and visually reviewed. The Windows icon is a format conversion of the logo. No third-party brand mark is intentionally included. Inter's separate license is bundled alongside the font.
